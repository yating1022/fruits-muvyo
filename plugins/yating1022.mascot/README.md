# 祖国人

把 Muvyo 的慕慕 AI 助手换成「祖国人」：只替换名字和立绘，慕慕的能力、权限和对话方式都不变。不联网，也不运行任何逻辑。

需要 **Muvyo 3.11.1 或更新版本**；旧版本认不出 `mascot` 能力，安装时会报清单不合规。

## 文件

| 文件 | 说明 |
|---|---|
| `manifest.json` | 在 `capabilities.mascot` 里声明名字和各动作的立绘 |
| `main.js` | 空入口：插件包必须有入口文件，形象插件不需要写函数 |
| `mascot-*.png` 共 14 张 | 各动作的立绘，320×480、透明背景 |

## 立绘动作

| 动作 | 用途 |
|---|---|
| `idle` | 待机，也用作对话框头像 |
| `idle_blink` / `idle_talk` | 眨眼 / 说话 |
| `look_left` / `look_upleft` / `look_right` | 看向不同方向 |
| `waveA` / `waveB` | 挥手的两帧 |
| `point_left` | 指向左边（带路时） |
| `popcorn` | 吃爆米花（闲置时） |
| `thumbs` | 点赞（任务完成时） |
| `jump` / `crouch` / `sitsmile` | 跳起 / 蹲下 / 坐着笑 |

## 启用

装好并启用插件后，到「设置中心 → 插件 → 慕慕 AI 助手」的「慕慕」区块，把「慕慕形象」选成「祖国人」并保存。所有管理员看到的是同一个形象；停用或删除插件后自动回到官方慕慕。
